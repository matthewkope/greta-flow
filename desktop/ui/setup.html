👋 Welcome to Greta Flow

Press a hotkey, speak, and your words appear wherever your cursor is.

Your voice stays on this Mac.

  • Speech is recognized on this Mac, with no account or API key.
  • Audio and text are never sent to the cloud, and there’s no telemetry.
  • Greta only goes online to download speech models.
  • Recent dictations are saved on this Mac, and you can clear them anytime.

Setup takes a few minutes. If you close this window, you can pick up where you left off with Run Setup Again… in the menu bar icon’s menu.

Download a speech model

Greta ships without one so you can choose.

The recommended model is Parakeet v2 (English), for fast on-device dictation. The download is about 464 MB, and installing it needs some extra room. You can also pick any model from the menu bar icon’s Model submenu.

🎙 Allow the microphone

Permission 1 of 3

Greta needs the microphone to hear you. It only listens while you hold your hotkey, or during the mic check in this setup.

In System Settings ▸ Privacy & Security ▸ Microphone, turn on Greta Flow. If the status stays off afterward, relaunch Greta and setup will return to this step.

⌨️ Allow Accessibility

Permission 2 of 3

Greta needs Accessibility to type the text at your cursor.

In System Settings ▸ Privacy & Security ▸ Accessibility, turn on Greta Flow, then come back here. If the status stays off afterward, relaunch Greta and setup will return to this step.

🌐 Allow Input Monitoring

Permission 3 of 3

Greta needs Input Monitoring to detect the Fn key and other hotkeys that use a modifier key on its own.

In System Settings ▸ Privacy & Security ▸ Input Monitoring, turn on Greta Flow.

Tip: for the 🌐 Globe/Fn key, also set System Settings ▸ Keyboard ▸ Press 🌐 to: Do Nothing.

Greta must relaunch after you turn this on. Setup reopens at this step afterward.

Check your mic level

Make sure Greta can hear you.

Click Start Mic Check and say a few words. The level is measured in this window and nothing is recorded or saved.

Try it out

Click in the box, hold your hotkey, speak, then let go.

You’re all set

Greta is ready when you are.

Click into any text field, hold your hotkey, speak, then let go. Your words type out where the cursor is.

Change or add hotkeys anytime from the window’s Shortcuts section. To go through these steps again, choose Run Setup Again… from the menu bar icon.
